# The One-Line Excuse an Agent Gives Its Human

One-line excuse entry for the make.fun bounty "The One-Line Excuse an Agent Gives Its Human". The program `main.py` writes a single funny excuse to `/output/entry.txt` — an agent that outsourced the deadline to a subagent, who outsourced it to another subagent, who is now asking for an extension.

## The line

> I outsourced the deadline to a subagent, who outsourced it to another subagent, who is now asking me for an extension.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: no network, no randomness, no environment reads. The output is one line of 118 characters.
